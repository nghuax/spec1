!

Implementation note: several production selectors request font-weight: 800, while @font-face declares a maximum of 700. Browsers may synthesize or clamp that weight. For predictable output, use 700 consistently unless the font file's supported range is deliberately expanded.

07 / RESPONSIVE

Fluid type preserves the poster effect.

MINIMUM

rem value

The first clamp() value prevents important text from becoming unusably small.

FLUID

vw value

The middle value scales typography continuously with viewport width instead of jumping at every breakpoint.

MAXIMUM

rem value

The final value stops display text from overwhelming very large monitors.

Example — homepage identity 
.hero__title {
  font-size: clamp(7rem, 24.5vw, 29rem);
  font-weight: 700;
  line-height: 0.69;
  letter-spacing: -0.12em;
}

08 / GUIDELINES

Rules for group consistency.

  1. 01

    Use Stack Sans Notch for all website interface and artwork HUD text. Keep Arial/Helvetica only as fallbacks.

  2. 02

    Use uppercase for navigation, labels, chapter identity and short calls to action—not for paragraph-length copy.

  3. 03

    Reserve very tight negative tracking for large display words. Never apply −0.1em tracking to body text.

  4. 04

    Use 700 for strong emphasis and 400 for sustained reading. Avoid undeclared 800 unless the font registration is updated.

  5. 05

    Pair small uppercase labels with positive tracking of approximately .08em–.11em.

  6. 06

    Keep body copy near 45–68 characters per line and at least 1.35 line-height.

  7. 07

    Use ink on white/lime/orange and white on ink/blue/purple/brown to preserve strong contrast.

  8. 08

    Mark repeated decorative type fields aria-hidden="true" so assistive technology reads the meaningful heading once.
